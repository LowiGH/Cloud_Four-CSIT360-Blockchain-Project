# Cloud_Four-CSIT360-Blockchain-Project
Cloud Four is a next-gen cloud storage solution that prioritizes data ownership and security. By combining decentralized storage networks with blockchain, it moves beyond traditional centralized models, giving users full control over their files and ensuring privacy in the modern web.

## 📝 Features

- User notes/files management with categories (Personal, Home, Business)
- Full CRUD operations for notes: create, read, update, delete
- Search and filter notes by category or keywords
- Light and dark theme toggle
- Future integration with blockchain for ownership and decentralized storage
- Responsive, modern dashboard UI

---

## ⚙️ Getting Started
Prerequisites
Make sure you have installed:
- Node.js (v16 or later recommended)
- npm (comes with Node.js)
- Optional: yarn if preferred

Backend Setup
- Navigate to the backend folder:
  cd backend

- Install dependencies:
  npm install
  
- Start the backend server:
  npm run dev


Frontend Setup

- Navigate to the frontend folder:
  cd frontend

- Install dependencies:
  npm install

- Start the development server:
  npm start

---

🔗 API Endpoints
- GET /api/users — Fetch all notes
- POST /api/users — Create a new note
- PUT /api/users/:id — Update a note
- DELETE /api/users/:id — Delete a note

---

🎨 Dashboard UI
- Displays a grid of notes with categories
- Add new notes using the +Add button
- Search and filter notes
- Edit or delete existing notes
- Toggle light/dark themes
- Future enhancement: integrate user profiles and blockchain ownership features.
